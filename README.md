# VnE Spellcheck

Panel Premiere Pro kiểm tra chính tả tiếng Việt trong text của Essential Graphics / MOGRT (`Line 1`, `Line 2`…): lỗi định dạng, từ sai chính tả, quên bật bộ gõ, sót phím Telex và từ dùng sai theo ngữ cảnh. Chạy hoàn toàn offline.

Repo này chỉ chứa các bản phát hành.

## Cài lần đầu (macOS)

1. Vào [Releases](../../releases/latest), tải file `VnE-Spellcheck-<phiên bản>.zxp`.
2. Cài bằng [ZXPInstaller](https://zxpinstaller.com) (miễn phí, không cần đăng nhập): mở ứng dụng rồi kéo file `.zxp` vào cửa sổ của nó.
3. Mở lại Premiere Pro → **Window › Extensions › VnE Spellcheck**.

## Cập nhật

Không cần cài lại. Khi có bản mới, panel hiện thông báo **“Có bản mới”** → bấm **Cập nhật**, rồi **Mở bản mới**.
